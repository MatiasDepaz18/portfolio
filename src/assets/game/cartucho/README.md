# Cartucho SNES (referencia visual)

El cartucho de la sección Proyectos es **100% CSS** (flip card con dos
caras): no usa estas imágenes en runtime. Las fotos son solo referencia
de paleta y proporciones.

- `cartucho.jpeg` — frente: label azul `#6d7e9a → #7485a1` con arte
  navy `#323f52`. Ambas caras usan esta misma base azul.
- `cartucho-atras.jpg` — reverso: misma base azul con textura de mold
  lines; los textos embossed van en navy `#3a4a68`.

Colores y detalles en `src/app/components/projects/cartridge/cartridge.css`.
Aspect de las caras: `1.64 / 1` (el del cuerpo del cartucho en las fotos).
